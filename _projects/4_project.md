ACE (AI-based Cartography of Ensembles) is an end-to-end 3D pipeline for mapping local cell activity in tera-voxel scale (~1TB per sample) light sheet microscopy datasets.

**Key contributions:**
- Designed and implemented an end-to-end 3D pipeline for mapping local neuronal ensembles brain-wide.
- Engineered an ensemble of convolutional and vision transformer-based models for soma segmentation.
- Integrated Monte Carlo dropout for probabilistic model uncertainty estimation.
- Optimized cluster-wise permutation statistical analysis for high-dimensional whole-brain microscopy data.
- Published in *Nature Methods* (Jan. 2025).

**Technologies:** Python · PyTorch · Fiji · Bash · Docker · Git

**Period:** Jan. 2020 – Jan. 2025
