A foundation deep learning model for object segmentation in microscopy datasets, pretrained on data from multiple imaging centers and modalities.

**Key contributions:**
- Gathered approximately 3 million 3D image patches from different centers and modalities for pretraining.
- Applied the 3DINO self-supervised learning approach for large-scale pretraining.
- Finetuned the model for axon, soma, and vascular segmentation tasks.
- Benchmarked against state-of-the-art segmentation models.

**Technologies:** Python · PyTorch · Bash · Git · 3DINO · Self-supervised Learning

**Period:** Jan. 2023 – Dec. 2025
