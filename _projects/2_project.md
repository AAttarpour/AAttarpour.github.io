Working on a foundation deep learning model for object detection and segmentation in CryoET 3D tomograms.

**Key contributions:**
- Gathered around 1,600 3D tomograms and generated more than 350,000 3D patches for pretraining.
- Applied the 3DINO self-supervised learning approach for large-scale pretraining.
- Finetuning the model on different downstream tasks and benchmarking against baseline models (in progress).

**Technologies:** Python · PyTorch · 3DINO · Self-supervised Learning

**Period:** Dec. 2025 – Present
